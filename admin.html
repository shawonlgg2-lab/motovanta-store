CSV IMPORT

Import product list

Choose marketplace and upload a CSV. Existing products with the same marketplace + external product ID are updated; rows without an ID are added as new products.

Expected headers: name, description, image_url, affiliate_url, price_label, currency, external_product_id, category_slug, commission_rate, status. Optional: price_amount (number), vehicle_type (motorcycle/car/universal), brand. Required: name and affiliate_url. Use only links and data you are permitted to use under your affiliate programme.
